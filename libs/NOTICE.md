# Bundled dependencies

AceConfig, AceGUI and CallbackHandler components are unmodified upstream files from WoWUIDev/Ace3 commit
a3604956e6e98a2b41144e7dbffadb21b917f828, with the ColorPicker widget updated from commit
e37c055f0817fd733ee486b813da14dc8b1568e8. Their license is in Ace3-LICENSE.txt.
LibSharedMedia is an unmodified upstream file from the official v12.1.2 tag
(https://repos.curseforge.com/wow/libsharedmedia-3-0/tags/v12.1.2/), retrieved 2026-10-13.
LibSharedMedia and SharedMediaWidgets retain their upstream notices.
Forever rank data attribution is in SpellRankData/LICENSE.txt.
